# About Us Page - User Guide

## 📋 Overview
Yeh guide aapko batayegi ke kaise About Us page ko manage karein aur team members aur customer reviews kaise add karein.

---

## 🚀 Quick Start

### Step 1: Admin Panel Mein Login Karein
1. Website par login karein (admin account se)
2. Admin Panel par jayein (`/admin`)
3. "About Us" card par click karein

---

## 👥 Team Members Kaise Add Karein

### Method:
1. **Admin Panel** → **About Us** page par jayein
2. **Section 3: Team Members** section mein scroll karein
3. **"Add New Team Member"** box mein:
   - **Name**: Team member ka naam (e.g., "Talha Saleem")
   - **Role**: Unka role/position (e.g., "CEO", "Designer", "Manager")
   - **Picture URL**: Unki photo ka URL (e.g., `https://example.com/photo.jpg`)
4. **"Add Member"** button click karein
5. Member list mein add ho jayega
6. **"Save All Changes"** button click karein (page ke bottom par)

### Important Points:
- Maximum **8 team members** add kar sakte hain
- Picture URL optional hai - agar nahi diya to first letter show hoga
- Kisi member ko remove karne ke liye unke card ke saath **"Remove"** button click karein

### Example:
```
Name: Talha Saleem
Role: CEO & Founder
Picture URL: https://example.com/talha.jpg
```

---

## ⭐ Customer Reviews Kaise Add Karein

### Method:
1. **Admin Panel** → **About Us** page par jayein
2. **Section 4: Customer Reviews** section mein scroll karein
3. **"Add New Review"** box mein:
   - **Customer Name**: Customer ka naam (e.g., "Ahmed Khan")
   - **Review**: Unka review text
   - **Rating**: 1 se 5 stars select karein
4. **"Add Review"** button click karein
5. Review list mein add ho jayega
6. **"Save All Changes"** button click karein (page ke bottom par)

### Important Points:
- **Unlimited reviews** add kar sakte hain
- Rating 1-5 stars ke beech select karein
- Kisi review ko remove karne ke liye unke card ke saath **"Remove"** button click karein

### Example:
```
Customer Name: Ahmed Khan
Review: Excellent quality products! Very satisfied with my purchase.
Rating: 5 Stars
```

---

## 🖼️ Images Kaise Add Karein

### Section 1 & 2 Mein Images:
1. **Section 1: Quality** ya **Section 2: Success Story** mein jayein
2. **"Image URL"** field mein image ka URL paste karein
3. **"Save All Changes"** click karein

### Image URL Format:
- Direct image link: `https://example.com/image.jpg`
- Cloud storage: `https://cloudinary.com/image.jpg`
- Base64: Bhi use kar sakte hain (but recommended nahi hai)

---

## 💾 Changes Save Karna

**Important**: Har baar changes ke baad **"Save All Changes"** button (page ke bottom par) zaroor click karein, warna changes save nahi honge!

---

## 👀 Preview Dekhna

Changes save karne ke baad:
1. `/about-us` page par jayein
2. Apne changes dekhein
3. Agar kuch change karna ho to wapas admin panel mein jayein

---

## ❓ Common Issues

### Problem: Changes Save Nahi Ho Rahe
**Solution**: 
- Check karein ke aap admin account se login hain
- "Save All Changes" button click kiya hai ya nahi
- Browser console mein errors check karein

### Problem: Images Show Nahi Ho Rahi
**Solution**:
- Image URL correct hai ya nahi check karein
- Image publicly accessible hai ya nahi verify karein
- URL format: `https://` se start hona chahiye

### Problem: Team Member Picture Show Nahi Ho Rahi
**Solution**:
- Picture URL field mein correct URL paste karein
- Agar URL nahi diya to first letter automatically show hoga

---

## 📞 Support

Agar koi problem ho to:
1. Browser console check karein (F12 press karein)
2. Network tab mein API calls check karein
3. Database connection verify karein
